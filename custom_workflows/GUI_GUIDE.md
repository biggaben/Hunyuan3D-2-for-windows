# Custom Workflows GUI - User Guide

## 🚀 Quick Start

### 1. Launch the GUI

**Windows:**
```bash
launch_gui.bat
```

**Linux/Mac:**
```bash
chmod +x launch_gui.sh
./launch_gui.sh
```

**Direct Python:**
```bash
cd custom_workflows
python custom_workflows_gui.py
```

The GUI will open in your default web browser at `http://127.0.0.1:7860`

### 2. Configure Settings (Optional)

Click on "⚙️ Global Settings" accordion to configure:

#### Model Settings
- **Model**: Choose between `h2` (Full 2.6B, best quality) or `mini` (0.6B, faster)
- **Device**: `cuda` for GPU, `cpu` for CPU-only
- **Enable Flash VDM**: Keep enabled for faster generation without quality loss

#### Processing Options
- **Enable Face Processing**: Auto-detect and align faces (for portraits)
- **Enable Image Enhancement**: Sharpening and illumination normalization

#### Generation Settings
- **Inference Steps**: 20-100 (50 recommended for best quality)
- **Guidance Scale**: 1.0-15.0 (7.5 recommended)
- **Octree Resolution**: 128-512 (384 for high detail, requires more VRAM)

#### Export Settings
- **Export GLB**: Include GLB format output
- **Export OBJ**: Include OBJ format output (with MTL material)
- **Extract Texture as Separate PNG**: Save texture as standalone PNG file

## 📋 Workflow Tabs

### 🖼️ Single Image Workflow

**Best for:** Portraits, detailed objects, single images

**Steps:**
1. Upload an image
2. Check "Portrait Mode" if the image contains a face
3. Set output directory (default: `outputs`)
4. Click "🚀 Generate 3D Model"
5. Wait for processing (progress shown)
6. Download results: GLB, OBJ, and/or texture PNG

**Tips:**
- Portrait mode automatically detects and centers faces
- Higher octree resolution = more detail but slower
- Image enhancement improves sharpness and lighting

### 📐 Multiview Workflow

**Best for:** Complex objects, multiple viewing angles

**Steps:**
1. Upload at least one view (front recommended)
2. Optionally upload back, left, and/or right views
3. Set output directory and name
4. Check "Use Turbo Model" for faster (but lower quality) results
5. Click "🚀 Generate from Multiview"
6. Download results

**Tips:**
- More views = better quality
- Front view is used as texture reference
- Turbo model is 2-3x faster but slightly lower quality

### 📦 Batch Processing Workflow

**Best for:** Processing multiple images with same settings

**Steps:**
1. Click "Upload Images" and select multiple files
2. Check "Process as Portraits" if all are portraits
3. Set output directory (default: `batch_outputs`)
4. Check "Skip Existing Outputs" to avoid reprocessing
5. Click "🚀 Process Batch"
6. Monitor progress in status box
7. View generated textures in gallery

**Tips:**
- All images use the same global settings
- Progress shown for each image
- Failed images don't stop the batch
- Results saved with batch_N naming

### 🎨 Texture Extraction Workflow

**Best for:** Extracting textures from existing models

**Steps:**
1. Upload a GLB or OBJ file
2. Optionally specify output path
3. Click "🎨 Extract Texture"
4. Download extracted PNG texture

**Tips:**
- Works with models generated by this tool or others
- Extracts embedded textures from GLB/OBJ files
- Output is always PNG format

## ⚙️ Configuration File

All settings can be saved/loaded from `workflow_config.yaml`:

```yaml
model:
  type: 'h2'  # or 'mini'
  device: 'cuda'
  enable_flashvdm: true

face_processing:
  enabled: true
  confidence_threshold: 0.5
  face_padding: 0.3

image_enhancement:
  enabled: true
  sharpness_factor: 1.5
  normalize_illumination: true

generation:
  num_inference_steps: 50
  guidance_scale: 7.5
  octree_resolution: 384
  num_chunks: 20000
  seed: 12345

texture:
  enabled: true
  target_face_count: 50000
  render_size: 2048
  texture_size: 2048

export:
  formats: ['glb', 'obj']
  extract_texture: true
  include_normals: true

output:
  directory: 'outputs'
  naming_pattern: '{name}_textured'
```

Edit this file to change defaults, or use the GUI settings panel.

## 💾 Output Files

Each workflow generates:

### GLB Format (if enabled)
- `*_textured.glb` - Complete model with embedded texture
- Compatible with: Blender, Unity, Unreal Engine, web viewers
- Single file, easy to share

### OBJ Format (if enabled)
- `*_textured.obj` - Mesh geometry
- `*_textured.mtl` - Material definition
- `*_textured.png` - Texture file (referenced by MTL)
- Compatible with: Most 3D software, Maya, 3ds Max, ZBrush

### Separate Texture (if enabled)
- `*_texture.png` - Standalone texture map (2048x2048)
- Can be edited in Photoshop, GIMP, Substance Painter
- Re-apply to model after editing

## 🔧 Troubleshooting

### GPU Out of Memory
**Solution:** Reduce octree resolution or use mini model
- Try: 256 → 128 octree
- Or: h2 → mini model
- Or: Close other GPU applications

### Face Not Detected
**Solution:** 
- Ensure face is clearly visible
- Try cropping image closer to face
- Adjust confidence_threshold in config (lower = more sensitive)

### Slow Processing
**Solutions:**
- Use mini model instead of h2
- Reduce inference steps (50 → 30)
- Reduce octree resolution (384 → 256)
- Enable Flash VDM if not already enabled

### Texture Quality Issues
**Solutions:**
- Increase texture_size in config (2048 → 4096)
- Use higher sharpness_factor (1.5 → 2.0)
- Enable image enhancement
- Provide higher resolution input image

### Model Not Loading
**Solutions:**
- Check internet connection (models download on first use)
- Verify sufficient disk space (~10GB for models)
- Check console for error messages

## 🎓 Tips & Best Practices

### For Best Results

1. **Input Images:**
   - High resolution (1024px+ recommended)
   - Good lighting, clear subject
   - Minimal background clutter
   - PNG or JPG format

2. **Portraits:**
   - Face should be centered and well-lit
   - Enable "Portrait Mode"
   - Use face processing + image enhancement
   - Single face works best

3. **Objects:**
   - Clear silhouette
   - Even lighting
   - Neutral or simple background
   - Multiple views for complex shapes

4. **Batch Processing:**
   - Use consistent image sizes
   - Similar subject matter
   - Same quality settings
   - Enable "Skip Existing" for resume capability

### Workflow Optimization

1. **Start with Fast Preview:**
   - Test with mini model, low settings
   - Verify composition and subject
   - Iterate quickly

2. **Refine with High Quality:**
   - Once satisfied, use full h2 model
   - Increase steps and octree
   - Enable all enhancements

3. **Export Appropriately:**
   - GLB for game engines, web
   - OBJ for traditional 3D software
   - Separate PNG for texture editing

## 🔄 Updates

To update settings without restarting:
1. Edit `workflow_config.yaml`
2. Refresh the GUI (reload page)
3. New settings will be used for next generation

To apply new settings to current session:
1. Change settings in GUI
2. Settings apply immediately to next generation
3. Original config file unchanged (edit manually to save)
